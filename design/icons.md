# Icons, favicon and splash screens

Generated by `design/tools/export-icons.mjs` from the mark geometry in `design/tools/mark.mjs`
(the same paths as `src/components/brand/KeyTagMark.tsx`). Re-run it after any change:
`cd design/tools && npm install && node export-icons.mjs && node icon-board.mjs`.

## Home-screen label check: "Our Suites"

Measured in Chromium with the platform fonts, the label is 51 px wide in SF at 12 px (iOS), 55 px in
SF at 13 px (iOS Larger Text) and 55 px in Roboto at 12 px (Android). The iOS label box is about
74–80 pt and the Android one about 72–80 dp, so at 10 characters "Our Suites" fits without
truncation on both, with about 20 px to spare. A mock is shown in `design/checkpoints/cp1/icons.png`.
Still check it on a real device after install, because Android launchers vary.
